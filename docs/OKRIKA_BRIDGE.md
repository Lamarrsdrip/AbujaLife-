# Okrika bridge

AbujaLife should make Okrika useful inside the fantasy without becoming a billboard.

Examples:
- in-game phone has `Okrika` under a clearly labeled real-world section
- contextual handoff: player browsing a virtual phone shop can optionally discover real listings
- virtual billboards can promote curated Okrika categories/events
- player profile can expose a separate Okrika seller identity only with consent

Rules:
- real items use real money and Okrika checkout
- Abuja Naira never crosses into physical commerce
- deep links carry campaign/district attribution
- user understands they are leaving game commerce for real commerce
