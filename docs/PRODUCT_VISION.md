# Product vision

AbujaLife is a persistent social city, not a menu simulator.

The player should spend most of a session **inside the world**. Menus exist only for things that naturally belong on a phone: messages, map, rides, bank/wallet display, marketplace search and events.

## Core loop

Wake at home -> maintain needs -> travel -> work/activity -> earn -> socialize/explore -> spend/invest -> improve home/style/vehicle/status -> unlock opportunity -> repeat.

## Long-term loops

- career reputation
- property ladder
- vehicle ownership
- fashion/identity
- friendships and groups
- business ownership
- district reputation
- collections/achievements
- seasonal city events
- fictional civic roles

## Anti-patterns

- floating cards pretending to be locations
- teleporting for every action
- balance/client authority
- five currencies
- pay-to-win social status
- giant UI covering the environment
- cloned GTA/LagosLife branding or assets
