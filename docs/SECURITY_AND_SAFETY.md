# Security and safety

- Authenticated server session required for persistent operations.
- Rate-limit chat, purchases, movement snapshots and invite spam.
- Never trust client price, reward, balance, ownership or cooldown timestamps.
- Signed server events for valuable state changes.
- UGC moderation and report/block/mute from day one.
- Private-by-default handling for minors if age policy later allows them; legal review required before launch.
- Anti-cheat uses impossible movement/economy detection first; avoid invasive device surveillance.
- Payment webhooks/receipts must be replay-safe.
